# The Midnight Museum Mysteries V2

Это обновление существующей игры: сохранены её игровой цикл, карта, блокнот, управление, озвучивание и проверка ответов. Активный набор теперь соответствует MD V2: **6 станций, 17 заданий, 170 раундов**, распределение заданий **3 / 3 / 3 / 2 / 3 / 3**.

## Запуск готовой игры

Дважды щёлкните **START_GAME.cmd**. Игра откроется по адресу **http://127.0.0.1:8080**. Окно командной строки обслуживает игру; после занятия закройте его или нажмите Ctrl+C. Готовая сборка находится в `dist/`. Для запуска сборки нужны только Node.js и эта папка; интернет не нужен.

Открывать `index.html` двойным щелчком больше не нужно: V2 использует модульные импорты и постоянный адрес localhost для сохранений.

## Разработка и сборка

```powershell
npm install
npm run dev
```

Локальная разработка: http://127.0.0.1:8080. Для подготовки готовой версии:

```powershell
npm run build
npm start
```

После изменения исходного кода запускайте сборку заново. Если порт 8080 занят другой копией игры, остановите её. `npm install` нужен один раз для разработки и требует доступа к реестру npm; самой игре внешние сервисы не нужны.

## Управление уроком

- **START** — новое расследование. **CONTINUE** — продолжить сохранённую V2-сессию. При загрузке сначала открывается главное меню.
- **START AGAIN** предлагает подтверждение. **CANCEL** сохраняет текущий урок, **YES, START AGAIN** создаёт новую V2-сессию и новый порядок карточек. Старый ключ сохранения V1 не удаляется.
- **HOME / SAVE & EXIT** сохраняют урок и возвращают в меню. Продолжение доступно в том же браузере, профиле и по тому же адресу. Хранилище браузера не следует очищать.
- **CLASSROOM / QUICK** — режим по умолчанию. Обычно это вопросы 1–6. Для картин и поиска отличий — **1, 2, 3, 6, 7**, чтобы показать обе сцены. **More questions** открывает оставшиеся раунды; **FULL** содержит все десять.
- В задании грамматики правильные ответы собирают часы. В Quick кнопка **Finish clock** честно достраивает оставшиеся стадии, без очков за нерешённые вопросы. Пропущенные цифры также отмечаются как автоматически заполненные.
- **BACK** не удаляет уже полученные очки, предметы или улики. **SKIP** отмечает вопрос как пропущенный, без XP. Неправильный ответ не отнимает очки.
- Картины и цифры часов: перетаскивание или щелчок по предмету, затем по месту. Профессии: выберите карточку действия, затем человека. Владельцы: выберите человека и его предмет; можно перетащить предмет на владельца.
- В задании иероглифов нажмите на символ, чтобы открыть три слова. В гардеробе нажимайте на одежду: мумия не одевается.
- Память: 12 секунд показываются все 10 предметов. Затем исчезает ровно один; остальные сохраняют места. Можно раньше нажать **Ready**. Для устного ответа откройте **Reveal missing object**, затем в Teacher Mode нажмите **MARK CORRECT**.
- **REPEAT** воспроизводит текст через доступный английский системный голос и повторяет анимацию сборки. Учитель может читать сам. **Sound off** отключает голос и сигналы.
- **Ctrl+Shift+T** включает ответы учителя и **MARK CORRECT**. После перезагрузки ответы снова скрыты.
- **Tab / Enter** выбирают кнопки, **стрелки** перемещают фокус, **Space** без фокуса на кнопке повторяет текст, **Esc** закрывает окно.
- Таймер предлагает расписание **3 + 6×7 + 5 минут**, не переключая задания автоматически. После 50 минут доступен **Wrap Up**: совместно выберите подозреваемого и перейдите к финалу. Нерешённые вопросы сохраняются как нерешённые; недобытые улики не подменяются вымышленными.

## Структура проекта

- `src/main.tsx`, `src/App.tsx` — запуск React и подключение существующего движка.
- `game.js`, `style.css`, `scenes.js` — обновлённые компоненты и логика прежней игры.
- `src/data/museumGameV2.json` — 170 записей из таблиц MD V2; `museumGameV2.ts` — типизированный импорт.
- `src/data/assetManifestV2.ts` — активный импорт путей V2; `assetManifestV2.json` — исходный реестр файлов и размеров.
- `src/data/differenceHotspotsV2.json` — активные прямоугольники отличий.
- `src/data/paintingLayoutV2.json` — размеры и положения десяти предметов в картинах по видимым границам PNG; три звезды занимают три отдельных места. Подробности — `PAINTING_FIT_NOTES.md`.
- `src/state/session.ts` — схема, проверка сохранений, перемешивание с seed.
- `src/proceduralAssets.js` — дополнительные детерминированные рисунки предметов фонарика, отсутствующие в поставке V2. Они не заимствуются из V1 и не являются заглушками.
- `public/assets/museum/v2/` — исходная поставка, нейтральный мышонок без ключа и отдельные исправленные изображения в `repaired/`. Все оригиналы сохранены; манифест направляет прежние ID на исправленные файлы. Метод и промпты: `docs/image-repair/generated-assets.json`, `IMAGEGEN_NOTES_V2.md`.
- Карточки показывают PNG целиком через `object-fit: contain`, без дополнительного кадрирования. Ранее измеренные границы `src/data/assetLayoutV2.json` больше не применяются.
- `archive/v1/` — копия прежнего кода до обновления; `tests/legacy/` — прежний тест.
- Старые `gameData.json`, `assetManifest.json`, `differenceHotspots.json` и `data.js` сохранены для истории, но больше не импортируются активной игрой.

## Проверки

```powershell
npm run build
npm test
python tools/verify_v2_assets.py
```

Браузерные тесты используют установленный Google Chrome и Playwright. Проверка PNG требует Pillow. Скриншоты и результаты сохраняются в `test-results/v2/`.

`python tools/build_v2_data.py` повторно извлекает утверждённые строки из MD V2. После изменения таблиц проверьте явные соответствия ответов в этом скрипте и пересоберите игру. `tools/update_engine_v2.py` — архив одноразовой миграции; повторно запускать его не требуется.
