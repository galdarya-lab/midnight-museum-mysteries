# Результат обновления The Midnight Museum Mysteries V2

> Дополнение после визуальной проверки: первоначальные тесты загрузки не обнаружили повреждённые фрагменты внутри ряда исходных PNG. Исправления графики и новые визуальные проверки описаны в `IMAGE_REPAIR_REPORT.md`. Дополнительное кадрирование карточек отключено; прежнее описание CSS view-box ниже относится к предыдущей сборке.

Обновлён существующий проект; исходный движок и полезные компоненты сохранены. Копия кода до изменений — `archive/v1/`. Старые файлы ассетов и исходные данные V1 не удалялись и не перезаписывались.

## Структура и импорты

- Новые `assetManifestV2.ts`, `assetManifestV2.json`, `differenceHotspotsV2.json` перенесены из корня в `src/data/`.
- `src/main.tsx` напрямую импортирует манифест TypeScript, JSON отличий и новый датасет через `museumGameV2.ts`. Дубликаты из корня не используются.
- Все пути `/assets/museum/v2/...` разрешаются через public-каталог Vite и готовы к `npm run build`. В активной игре нет импортов графики V1.
- React запускает прежний движок из `game.js`. Сохранены карта, блокнот, игровое состояние, методы проверки, мышь/клавиатура, звук и сертификат; обновлены правила и необходимые механики.

## Соответствие MD V2

Ровно **6 станций, 17 заданий, 170 уникальных вопросов**, по станциям **[3,3,3,2,3,3]**. Удалены из активной логики скелет и лабиринт. Заменены портреты, профессии, гардероб, сцены картин, отличия, части и действия динозавров, предметы памяти и графика часов.

Quick использует явно заданные coreQuestionIds. Для двух картин и двух пар отличий — **[1,2,3,6,7]**. Всего в Quick **100 основных раундов**. Бонусные вопросы картин идут **[4,5,8,9,10]**, без повторения уже пройденного ядра. Full содержит все 170 раундов.

Реализованы START / CONTINUE / START AGAIN с CANCEL и подтверждением, HOME / SAVE & EXIT, отдельный ключ `midnightMuseum:v2:save`, валидация сохранения, устойчивые ID, сохранённые seed-порядки карточек и независимое перемешивание сторон matching. Старый ключ V1 остаётся нетронутым. Ответы, пропуски, позиции предметов, улики, таймер, настройки, фаза памяти и 10 стадий часов сохраняются.

Finish clock явно достраивает часы без XP за несделанные вопросы. Пропуск также не даёт XP. Повторный правильный ответ не удваивает очки. Последняя улика доступна после правильного выбора мышонка. Wrap Up появляется после 50 минут и позволяет обсудить разгадку без подмены нерешённых вопросов правильными ответами.

## Проверенные особенности поставленных материалов

1. В поставленных 197 изображениях нет отдельных V2-предметов для Magic Flashlight и управляемых слоёв Security Camera Check. Для этих экранов используются явно заданные функциональные Canvas-рисунки; фон холла берётся из V2. Это самостоятельные кодовые иллюстрации, а не старые картинки, эмодзи или заглушки. Они проще 3D-персонажей и не выдаются за новые 3D-рендеры.
2. Исходный `suspect_grey_mouse_3d.png` содержит ключ, шарф и лишний фрагмент у края. Он сохранён, но не используется до разгадки. Создан отдельный нейтральный 3D-портрет без ключа и аксессуаров: `public/assets/museum/v2/characters/suspect_grey_mouse_neutral_3d.png`. Источник, метод imagegen и полный финальный промпт — в `IMAGEGEN_NOTES_V2.md`.
3. Прозрачные поля отдельных PNG были слишком велики для проектора. Для карточек добавлены измеренные CSS view-box границы в `src/data/assetLayoutV2.json`. Файлы не обрезаются и не переписываются. Некоторые поставленные небольшие иллюстрации остаются более простыми по стилю, чем основные 3D-персонажи.
4. Номер A, встроенный в исходные изображения отличий, перекрывается правильной HTML-меткой A/B, чтобы не путать детей.
