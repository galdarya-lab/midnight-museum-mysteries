# Размер предметов в картинах

Предметы больше не масштабируются по полному квадратному PNG с прозрачными полями. При установке видимая часть рисунка занимает прямоугольник соответствующего силуэта на картине. Настроены все десять предметов Village / Castle; исходные изображения не переписываются.

- `src/data/paintingLayoutV2.json` хранит отдельные координаты и размеры силуэтов на полотне 724×565, а также границы видимого содержимого каждого PNG.
- `tools/build_painting_layout.py` измеряет прозрачные поля. После замены предметов этот файл можно пересоздать.
- Карточки выбора по-прежнему показывают рисунок целиком. Размер и положение меняются только после правильного размещения.
- Три звезды раскладываются по трём отдельным силуэтам, но остаются одним игровым действием и дают 10 XP один раз.
- Сохранённые ранее предметы автоматически восстанавливаются в новых размерах. Номера вопросов, ответы и сохранения не менялись.

Проверено: десять правильных размещений, перетаскивание и два клика, точное соответствие видимых границ заданным прямоугольникам, 1366×768 / 1920×1080, восстановление после перезагрузки без повторного начисления очков.

Команды: `npm run build`, `node tests/painting-fit.cjs`.
